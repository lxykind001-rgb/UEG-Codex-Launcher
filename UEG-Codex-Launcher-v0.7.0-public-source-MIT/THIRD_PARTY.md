# Upstream attribution

This project adapts the standalone UEG preview from [dsh-550c-boot](https://github.com/yannicksong0106/dsh-550c-boot). The imported `wwwroot/ueg.html` and required `wwwroot/assets/` files retain the upstream attribution in [`upstream-attribution/LICENSE`](upstream-attribution/LICENSE) and [`upstream-attribution/CREDITS.md`](upstream-attribution/CREDITS.md). The exact imported revision is recorded in [`UPSTREAM_COMMIT.txt`](upstream-attribution/UPSTREAM_COMMIT.txt). The upstream project identifies Ziyang Song as the MIT-licensed plugin author and credits Voidpocket for the original animation page.

The ten optional local WAV files in the working copy are **not included** in this public source package because their redistribution rights were not independently established. Default audio is off. No official Codex binary, icon, account data, or personal settings are included.

The root `LICENSE` covers this project's original launcher and plugin additions; it does not replace the upstream copyright notice.
